# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of Drova.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Tim275/drova/security/advisories/new)
instead of opening a public issue.

We aim to acknowledge new reports within 72 hours and will share a remediation
timeline after triage. Thank you for helping keep Drova and its users safe.
